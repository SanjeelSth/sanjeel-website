Project Overview

Project Resilience demonstrates enterprise-grade high availability across a simulated multi-router network. The design achieves zero-downtime objectives through Hot Standby Router Protocol (HSRP), dual-ISP failover, EtherChannel link aggregation, VLAN segmentation, OSPF dynamic routing, and NAT/PAT — mirroring production techniques used in real-world enterprise environments.

Network Topology

A hierarchical three-tier design: an ISP router at the top, two distribution/gateway routers (R1 and R2) running HSRP, and two access switches (SW1 and SW2) serving end hosts across two VLANs. EtherChannel bundles connect the switches to the routers.

HSRP Failover

HSRP was deployed on R1 and R2 for seamless gateway failover. When R1 was taken offline, R2 automatically transitioned from Standby → Speak → Active for both VLAN 10 (Group 10) and VLAN 20 (Group 20) — hosts never lost connectivity.

%HSRP-6-STATECHANGE: Gig0/0.20 Grp 20 Speak -> Standby
%HSRP-6-STATECHANGE: Gig0/0.20 Grp 20 Standby -> Active
%HSRP-6-STATECHANGE: Gig0/0.10 Grp 10 Standby -> Active

Result: Sub-3-second HSRP switchover confirmed. R2 held virtual IPs 192.168.10.1 and 192.168.20.1 with priority 100 — zero host-visible downtime.

Dual-ISP & Floating Static Routes

The ISP Router was configured with Gig0/0 (facing R1) and Gig0/1 (facing R2), plus Loopback0 (9.9.9.9) simulating the internet. Floating routes ensure automatic traffic failover to R2 if the R1 WAN link drops.

ISP(config)# ip route 0.0.0.0 0.0.0.0 8.8.8.1      ! Primary – AD 1
ISP(config)# ip route 0.0.0.0 0.0.0.0 8.8.8.5 10  ! Floating – AD 10

EtherChannel Link Aggregation

EtherChannel (Port-Channel 1) aggregates switch uplinks on SW1 and SW2, eliminating single-points-of-failure on trunk links. Configured with LACP active mode on interfaces Fa0/23–24.

SW1(config)# interface range fa0/23 - 24
SW1(config-if-range)# channel-group 1 mode active
SW1(config)# int port-channel 1
SW1(config-if)# switchport mode trunk

NAT/PAT & OSPF

R1 is the primary gateway running OSPF Area 0 with default-information originate to push the default route to all internal routers. NAT/PAT overload translates all VLAN traffic to the single WAN IP on Gig0/1.

R1(config)# router ospf 1
R1(config-router)# network 192.168.10.0 0.0.0.255 area 0
R1(config-router)# network 192.168.20.0 0.0.0.255 area 0
R1(config-router)# default-information originate
R1(config)# access-list 1 permit 192.168.10.0 0.0.0.255
R1(config)# access-list 1 permit 192.168.20.0 0.0.0.255
R1(config)# ip nat inside source list 1 interface g0/1 overload
